## 2. 공통 규칙

### 2.1 파티 규칙

1. **나옹은 파티 배열의 맨 끝**이다(QA 피드백 2). 상금 계산은 전투에 마지막으로 나온 포켓몬이 아니라 `gTrainers[id].party[partySize-1].lvl`을 쓴다(`battle_script_commands.c:5373`). 지금 달맞이산(아보·나옹·또가스)·아지트·타워는 나옹이 끝이 아니다. 14개 모두 고친다.
2. 나옹은 파티 최고 레벨, 진화하지 않는다.
3. 기술 지정: `NO_ITEM_CUSTOM_MOVES`는 파티 전체의 구조체 형식을 바꾼다(`TrainerMonNoItemCustomMoves`, `battle_main.c:1580`). "나옹만 지정"은 엔진상 불가능하므로 **모든 포켓몬의 기술 4칸을 적는다**. 빈칸은 `MOVE_NONE`. 아래 표의 기술은 레벨업·기술머신으로 배울 수 있는 것만 골랐다(`level_up_learnsets.h`, `tmhm_learnsets.h` 확인).
4. IV·도구는 지금 값을 유지한다: #1~#12 `iv = 0`, 도구 없음 / #13 `iv = 100`, `FULL_RESTORE`×2 / #14 `iv = 255`, `FULL_RESTORE`×2.
5. AI 플래그는 그대로(`CHECK_BAD_MOVE | TRY_TO_FAINT | CHECK_VIABILITY`).
