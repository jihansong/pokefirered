Thunder Yellow v1.4 동기화본

최신 GBA와 같은 폴더에 있는 pokemonthyl_v1.4.sav를 사용하세요.
Codespaces 원본 saves/pokemonthyl_v1.4.sav는 보존했고 업데이트본은 saves/pokemonthyl_v1.4-synced.sav입니다.

반영 내용: Master Ball·Rare Candy·TinyMushroom·PP UP 99개, 부족한 파티 PP 보정, 기존 IV 2배 조정 유지(재2배 없음), 정상 PC 개체 도감 번호/중복 레벨 오름차순 정렬. 새로운 진행·도감·포켓몬의 경험치와 진화는 보존했습니다.
라프라스 Bad Egg는 이전 세이브에서 동일 개체의 유일한 정상 원본을 확인해 복원했습니다. 내루미 손상 개체는 정상 원본이 없어 BOX 2/22에 그대로 보존했습니다.

검증: 두 저장 세대 28개 섹션 체크섬, 허용 변경 외 원본 바이트 보존, 최신 ROM 실제 Continue·SAVE·종료 후 Continue(78→79) 통과. 검사용 진행 파일은 이 배포 SAV로 사용하지 않았습니다.

DELTA에서는 게임 내 CONTINUE로 불러오세요. 이전 Save State를 불러오면 과거의 메모리와 세이브로 이번 변경을 덮을 수 있습니다. 실제 DELTA 장치 FPS, 모든 지역 캠페인 및 모든 도감 UI 검증 완료를 뜻하지 않습니다. 호연 무로 도착 후 이동 막힘의 후속 검사는 계속 진행 중입니다.
