# v0.7.0 구현 계획 — 호연 1단계 "카이나 항구권"

v0.6.0("최강을 향한 길") 다음 버전. `docs/hoenn-open-plan.md`에서 확정한 방향대로 **호연을 단계별로 여는 첫 단계**다. 1단계 구역은 사용자가 고른 **A안 = Z1 카이나(슬레이트포트) 항구권 41개 맵**이고, 비행기 도착지인 카이나시티를 호연의 관문으로 확정한다. 이 문서는 계획만 담으며, 승인 전에는 코드를 바꾸지 않는다.

## 확정된 전제 (사용자 결정, `docs/hoenn-open-plan.md` 5.9절)

- 지형은 지금처럼 **열어 둔다**. 차단 NPC로 길을 막지 않고, 아직 이야기가 없는 구역에는 길을 막지 않는 "정비 중" 안내판 정도만 둔다. 대신 미개방 구역은 **안전 점검**(워프 목적지 유효성, 갇히거나 크래시 나는 문·계단)만 계속한다.
- 전설·스타터는 **한 플레이에 한 번만**. 칸토(셀리오 포함) 기존 획득 경로는 세이브 호환 때문에 그대로 두고, 호연 원래 장소는 플래그를 보고 갈린다. 1단계 구역에는 전설도 스타터도 없어 이번 단계에서는 해당 없음.
- 열리는 구역의 **NPC·표지판 대사는 전부 새로 쓴다**(에메랄드 원문 이식 금지). 옐로 맥락 = "공항으로 건너온 칸토 챔피언".
- 트레이너 레벨은 구역을 열 때 **일괄 상향**한다(1단계 Lv45~55).

## 브랜치와 공통 규칙

- 브랜치 `hoenn-stage1`(master = v0.6.0에서 분기). 항목마다 빌드 → 에뮬레이터 캡처 → 세이브 비교 → 커밋. push·머지·태그·패치·릴리스는 캡처 확인 뒤 요청이 있을 때만.
- 세이브 구조는 바꾸지 않는다. 새 기록은 호연용 빈 공간에만 둔다(아래 P3).
- 세이브 검사는 지금 4종(`v0.1.0` `v0.2.1` 사용자 세이브 `v0.5.1`)에 **호연 안에서 저장한 세이브 1개**를 더해 5종으로 늘린다.
- 이벤트마다 게임 안 힌트를 둔다. 호연 쪽 힌트는 카이나 포켓몬센터의 새 소문 수집가에 모은다.
- 새 그림은 없다(호연 인물·타일은 이미 이식되어 있고, 규칙상 이식분은 그대로 쓴다).
- 끝나면 `docs/hoenn-open-plan.md` 단계 기록과 공략집 새 장·이벤트 색인을 갱신한다.

## 3. 대사 새로 쓰기

- 대상: Z1의 **NPC 72명 + 표지판 60개 = 132개**. 지금은 에메랄드 원문의 첫 대사만 들어 있다.
- 방식: 맵별로 새 텍스트 파일을 만들고, 이식 스크립트가 덮어쓰지 않도록 `tools/hoenn_import/patches/` 아래에 둔다(로켓단 이벤트에서 쓴 방식과 같다).
- 톤: 호연 사람들이 "칸토에서 온 챔피언"을 어떻게 보는지, 배지가 여기서는 처음부터 다시라는 점, 바다·배·해저 이야기. 원작 정보(예: "이 도시는 무역항")는 뜻만 살려 새 문장으로 쓴다.
- 분량 기준: v0.5.0 로켓단 확장이 새 대사 약 60개였으므로 약 2배.

## 4. 레벨 정책 (P7)

- Z1 트레이너 49명의 원작 레벨은 Lv13~20이다. 칸토 챔피언이 건너오는 전제라 **Lv45~55**로 올린다.
- 방법: `tools/hoenn_levels.py`(새 도구)가 구역별 배율·상한을 받아 `src/data/trainer_parties_hoenn.h`를 다시 쓴다. 상대 순서는 유지하고(약한 트레이너는 45, 체육관 관장은 55), 체육관장 BRAWLY만 파티 구성도 원작 그대로 두되 레벨만 올린다.
- 야생 포켓몬 레벨은 **그대로 둔다**(도감 서식지 문서와 어긋나지 않게). 다만 카이나 소문 수집가가 "야생은 아직 약하다"는 한 줄로 이유를 설명한다. → 결정 5번.

## 5. 안전 점검 (차단 대신)

- `tools/check_map_integrity.py`와 `tools/hoenn_reachability.py`를 매 단계 돌려 워프 목적지·갇힘·크래시를 확인한다(v0.6.0 기준 0 오류).
- 아직 이야기가 없는 방향에는 **길을 막지 않는 안내판**만 둔다: 카이나 북쪽(110번 도로), 카이나 동쪽 바다(134번 도로), 106번 도로 북쪽(105번 도로), 카이나 배틀텐트. 문구는 "이 앞은 아직 준비 중"이라는 뜻을 게임 안 말투로.
- 호연 사천왕 방처럼 **문이 닫힌 막다른 방**은 v0.5.1에서 막았다. 다음 구역을 열 때 같은 종류를 다시 점검한다.
