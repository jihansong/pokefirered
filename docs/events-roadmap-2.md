# 이벤트 로드맵 2탄 (Thunder Yellow)

v0.1.0 이후에 추가를 검토할 이벤트 후보 15개다. 아직 구현하지 않았으며, 이 문서는 코드를 바꾸지 않는다.

- **A. 도시전설·삭제 데이터**: 개발 중 삭제됐다고 알려진 요소와 소문을 실제 이벤트로 만든 것.
- **B. HGSS·BW 요소 이식**: 후속작의 시스템을 FR/LG 엔진에 옮기는 것.
- **C. 피카츄 강화**: 스타터 피카츄(따라다니는 피카츄)와 관련된 확장.
- **D. 엔딩 이후**: 전당등록 뒤의 도전 콘텐츠.

위치는 1탄과 같이 이 저장소(FR/LG 기반)의 맵 이름으로 적었고, 새 맵이 필요한 곳은 "새 맵"으로 표시했다.

## 공통 전제

- **시계**: 현재는 실시간 시계가 없다. v0.1.0의 시간 조건은 모두 걸음 수로 센다(벌레잡기 대회 요일 `GAME_STAT_STEPS`÷256, 삐삐의 춤 달력 `VAR_MOON_PHASE_STEPS`, 빌의 정원 `VAR_BILLS_GARDEN_STEPS`). 3번처럼 "밤"이 필요한 후보는 9번 시간대 시스템에 의존한다.
- **그래픽 규칙**: 1탄의 원칙(새 그래픽은 기존 스프라이트 재색칠)을 유지한다. 12번 의상처럼 재색칠만으로 불가능한 항목은 "새 그림 필요"로 표시했다.
- **난이도 기준**(1탄과 같음)
  - **하**: 스크립트·텍스트, 기존 맵에 오브젝트 추가 정도.
  - **중**: 새 스페셜(C 코드)이나 새 그래픽, 작은 새 맵이 필요.
  - **상**: 새 시스템, 여러 맵에 걸친 연출, 전투·필드 엔진 수정이 필요.
- **새 리소스**: 플래그·변수는 대부분 필요하므로 따로 적지 않았다.
- **의존성**: 먼저 끝나야 하는 이벤트(1탄 번호는 "v0.1.0 이벤트 N")나 엔진 변경을 적었다.

### 9번 설계: 시간대 시스템

**1) 시계 소스 (RTC 유무)**

| 방식 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 실제 RTC | 에메랄드의 GPIO RTC 드라이버(pokeemerald `siirtc.c`·`rtc.c`)를 이식해 카트리지 시계를 읽는다. 이 저장소에는 RTC 드라이버가 없다(`src/field_tasks.c`에서 RS의 RTC 기능이 제거됨). | 현실 시간과 연동, HGSS와 같은 체감 | FR/LG 정품 카트리지에는 RTC 칩이 없어 실기에서 동작하지 않음. 에뮬레이터·일부 플래시카트만 지원 |
| B. 플레이 시간 가상 시계 | 기존 플레이 시간(`playTimeHours`/`playTimeMinutes`)에서 게임 내 시각을 계산(예: 현실 10분 = 게임 1시간). | 모든 환경에서 동작, 세이브만으로 재현 가능 | 현실 시간과 무관 |
| C. 걸음 수 가상 시계 | v0.1.0의 256걸음 달력을 시간대까지 확장. | 이미 쓰는 방식과 일관 | 가만히 있으면 시간이 멈춤 |

**권장**: A를 시도하고 RTC가 응답하지 않으면 B로 자동 전환한다. v0.1.0의 걸음 수 조건(벌레잡기 대회 요일, 삐삐의 춤 보름달, 빌의 정원 하루)은 새 시계의 "날짜"로 옮기되, 시계를 쓸 수 없는 환경에서는 기존 걸음 수 방식을 유지한다.

**2) 세이브 구조 영향**

- `SaveBlock2`에 RS에서 남은 `struct Time localTimeOffset`(0x098)과 `struct Time lastBerryTreeUpdate`(0x0A0)가 있으나 FR/LG는 쓰지 않는다. 방식 A의 시계 보정값과 방식 B의 기준 시각을 여기에 저장하면 **세이브 블록 크기와 배치를 바꾸지 않아도 된다**.
- 시간대 자체는 매번 계산하므로 저장하지 않는다. 시간대 이벤트의 "오늘 이미 함" 기록만 빈 변수(`VAR_0x40C4` 이후)에 날짜 번호로 저장한다.
- v0.1.0 세이브는 보정값이 0이므로 "시계 미설정"으로 보고, 처음 불러올 때 시계 설정 화면(RS식)을 한 번 띄운다. 기존 걸음 수 변수는 그대로 두어 이전 세이브와 호환한다.

**3) 출현표 분리 방식**

- 현재 `src/data/wild_encounters.json`은 맵마다 `land_mons`·`water_mons`·`rock_smash_mons`·`fishing_mons`를 하나씩 가진다(264개 항목).
- 맵 항목에 선택 필드 `land_mons_morning`·`land_mons_night`(필요하면 `water_mons_night` 등)를 추가하고, 없으면 기존 `land_mons`를 쓰는 **폴백 구조**로 한다. 모든 맵을 한꺼번에 고칠 필요가 없다.
- 템플릿(`wild_encounters.json.txt`)이 시간대별 `WildPokemonInfo`를 추가로 생성하고, `WildPokemonHeader`에 시간대별 포인터 배열을 둔다. `GetCurrentMapWildMonHeaderId` 이후 `GetTimeOfDay()`로 포인터를 고른다.
- 시간대 구간은 HGSS 값(아침 04:00~09:59, 낮 10:00~19:59, 밤 20:00~03:59)을 따른다.
- 영향 받는 기존 코드: 일반 조우, 달콤한향기, v0.1.0 필드 현상(이벤트 18)·벌레잡기 대회(이벤트 19)의 레벨 계산, 도감 분포 화면(`wild_pokemon_area.c`, 시간대별 표시 또는 합산).
- 선택 항목: 야외 맵 팔레트를 시간대별로 어둡게 하는 색조 처리(RS의 `UpdatePalettesWithTime` 참고).
