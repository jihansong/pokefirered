**원칙을 바꾼 이유**(9/24 추천 근거, 9/26 사용자 재확인):
1. 사용자 원 요구 "스타팅은 무조건 주인공이 다 얻게, 이벤트 기반"을 (A)는 채우지 못한다. 셀리오 지급은 이벤트가 아니고, 늦은 포스트게임(사파이어 반환) 뒤에만 열린다.
2. 칸토 옐로식(이상해씨·파이리·꼬부기를 각 도시 이벤트로)과 같은 구조가 된다.
3. 새로 여는 호연의 첫 구역에서 털보박사가 이야기의 중심에 선다(원작·애니 3기 모두 그렇다).
4. §5.9 Q5의 "다른 역할(도감 평가)"도 버리지 않고 함께 넣는다(4.2 E2).

**중복을 허용하면서 지킬 것**: 새 이벤트 셋은 각자 한 번만 준다(자체 플래그). 셀리오 쪽 대사는 바꾸지 않는다. 털보박사는 셀리오에게 이미 받은 세이브에서 "네트워크로 보낸 아이의 형제"라는 한 줄만 더한다(보상 변화 없음). 전설 "한 플레이 한 번"(§5.9 Q4)은 전설·환상에만 적용되며 스타터는 해당하지 않는다.

## 4. 이벤트 상세

공통: 대사는 모두 새로 쓴다("칸토 챔피언이 비행기로 건너왔고, 호연 배지는 0부터"). 피카츄 분기는 `FLAG_HOENN_PIKACHU_*` 방식(Z1과 같음). 좌표는 원작 `map.json`의 좌표(레이아웃이 같다)를 기준으로 하고, 디자이너가 확정한다.

**맵 진입 스크립트 규칙**: 옛 세이브는 새 숨김 플래그가 모두 0(= 보임)이다. 조건부로 보여야 하는 오브젝트는 `MAP_SCRIPT_ON_TRANSITION`에서 C special(`HoennZ3_SetupObjects`)이 상태를 보고 `FlagSet`/`FlagClear` 한다. 스크립트의 `specialvar` + `goto_if`는 ON_TRANSITION에서 믿을 수 없다(hoenn-open-plan 2절 메모, v0.6.0 경험).
