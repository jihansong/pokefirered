# Thunder Yellow Q9 후보 검수

- 메인 ROM은 Q8 유지. Q9 phase5 후보 빌드 성공, 최종 검사 중.
- Phase4에서 실제 Silver 6마리전 및 사천왕/챔피언 5전을 승리하고 명예의 전당 저장112→128·콜드 Continue 통과. 전체 관동→성도 자연 플레이 완주로 확대 주장하지 않음.
- 기존 세이브8개 load IDENTICAL 및 Continue 통과. 원본 내용/PC/도감 구조를 변경하지 않음.
- Misty 대화4분기·친선 승패·동행·5단계 팀 검증 통과. 친선전은 NPC 아군 협력 전투 구현과 별개이며 후자는 미완료.
- 실제 cold PokemonCenter 버퍼 손상은 Union Room 이름12바이트 내 종결 검사를 넣어 방지. 게임 NOLOAD EWRAM은 cold에서0 초기값; C initializer가 게임 초기화를 보장한다고 주장하지 않음. 동일 세이브 치유 후 PC/도감/스토리 바이트 보존 확인.
- 다지역 nurse QA cold 차이는 기존 Hoenn NPC 표시11플래그로 확인. 사용자 세이브를 수정하거나 비교 제외하지 않고 QA 최초 조건만 actual-source와 일치시키는 검사가 남음.
- Tohjo 앞타일·Surf·배지·기술은 올바름. 추가 UP 직후 남향 상태를 관측, 매프레임 진단 중. 지형을 임의 변경하지 않음.
- 기존 전역 event wiring 80 dead/16 empty promise, Route119 원작 대사55개 잔존은 미완료 범위로 기록. Q9 새 이벤트의 신규 문제와 분리 검수.
- Titlev8/Openingv7/Rocketv11 원본24개 및 SaveABI14섹터 보존은 phase4 이진 검수 통과. Phase5는 최종 검수 예정.
- 기존 Bad Egg1개 원본은 아직 미복원. DELTA Save State 문제와 새 cold nurse 버퍼 경로의 동일 원인이라고 단정하지 않음.
