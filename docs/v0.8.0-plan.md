# v0.8.0 구현 계획 — 호연 2단계: 무한시티와 자전거 도로

v0.7.0(호연 1단계, 카이나 항구권)에 이어지는 **호연 2단계**. `docs/hoenn-open-plan.md`의 단계 개방 로드맵에서 Z2로 묶인 35개 맵을 이야기와 함께 연다. 이 문서는 계획만 담으며, 승인 전에는 코드를 바꾸지 않는다.

## 0. 이 계획을 쓰기 전에 한 전수 점검 (2026-09-23)

v0.1.0~v0.7.0에 추가한 기능·이벤트를 **에뮬레이터로 다시 돌려** 확인했다. 결과는 아래 "부록 A"에 정리했다. 요약:

- 추가 이벤트 **46개를 실제로 작동시켜 확인**했고, 새로 발견된 게임 진행 불능 버그는 **없었다**(공항 문 회귀는 v0.7.0에서 이미 수정·출시).
- 아직 열지 않은 호연 구역에 **"주겠다고 말만 하고 주지 않는 NPC" 15명**이 남아 있다. 그 구역을 열 때 같이 고쳐야 한다. Z2에는 2명(무한시티 민가1, 트릭하우스 퍼즐6).
- 점검 도구 3개를 새로 만들었다(`tools/check_event_wiring.py`, `/root/qa-tools/eventcheck.py`, `savedit.py`의 `strong`·`day` 조작).

## 3. 대사 새로 쓰기

- 대상: Z2의 **NPC 59명 + 표지판 34개 = 93개**, 여기에 트레이너 60명의 인사·패배·후일담 3줄씩을 더하면 약 **270개**. 1단계(299개)와 비슷한 분량이다.
- 방식은 1단계와 같다: `tools/hoenn_import/patches/<Map>.text.inc`에 같은 라벨로 쓰면 `apply_patches.py`가 이식본을 지우고 덮어쓴다.
- **같이 고칠 것**: 무한시티 민가1과 트릭하우스 퍼즐6의 "주겠다고 말만 하는" 대사(부록 A 참고). 주지 않는 도구를 약속하지 않도록 고쳐 쓴다.

## 6. 순서

0. (완료 조건) 각 항목마다 빌드 → 에뮬레이터 확인 → 세이브 5종 비교 → 커밋. 마지막에 전체 오류 점검을 다시 한 번
1. 안내판 치우기 + Z2 안전 점검(`check_map_integrity`, `hoenn_reachability`, 맵 스모크 35개)
2. 레벨 도구 적용(Lv55~65) → 빌드·세이브 테스트
3. 이벤트 3(WATTSON·배지) → 1·2(자전거 도로) → 4(뉴 무한) → 5(트릭하우스 1~3) → 6·7
4. 대사 270개(맵 단위로 나눠서) + 빈 약속 2건 수정
5. 소문 수집가에 2단계 소문 추가(1단계에서 만든 `VAR_HOENN_RUMOR_STATE` 순환 확장)
6. 다음 구역(Z3·Z4) 경계에 "정비 중" 안내판
7. 문서·공략집 14장 → 캡처 확인 → v0.8.0

## 9. 106번 도로 "검은 화면"의 진짜 원인 (2026-09-23)

부록 A에 "하네스 아티팩트"로 적어 둔 것의 원인을 찾았다. 게임이 아니라 **`savedit.py`의 `warp`가 만든 세이브**가 잘못이었다.

- `warp`는 `SaveBlock1`의 `pos`·`location`·`continueGameWarp`만 바꾸고 **`mapLayoutId`(0x32)는 그대로 두었다**.
- 이어하기는 `LoadSaveblockMapHeader()`로 맵을 여는데, 헤더는 `location`에서 가져오지만 **레이아웃은 저장된 `mapLayoutId`에서** 가져온다(`src/overworld.c`의 `GetMapLayout`).
- 그래서 새 맵의 접속(connection) 정보를 **옛 맵의 가로 크기**로 채우게 되고, 위·아래 접속의 offset이 크면 `FillNorthConnection`이 `gBackupMapData` 밖에 쓴다. EWRAM이 깨지고 화면이 검게 멈춘다.
- 조건이 맞는 맵은 호연만이 아니다. **칸토 3번 도로(up 60)·13번 도로(up 48)** 도 같은 증상을 보였다. 실제 플레이(걸어 들어가기, 화강암 동굴에서 나오기, 그 자리에서 저장하고 이어하기)는 모두 정상이었다.
- 고친 곳: `savedit.py`의 `warp`가 목적지 맵의 `LAYOUT_*` 번호를 `mapLayoutId`에 같이 쓴다. 고친 뒤 106·113·116·118·123번 도로와 칸토 3·13번 도로가 전부 정상으로 뜬다.

**교훈**: 검은 화면을 봤을 때 "실제로 걸어 들어가서도 그런가"를 먼저 확인한다. 이번에는 실제 세이브로 저장→이어하기까지 해서 게임 쪽 결백을 확인한 뒤에 도구를 고쳤다.
