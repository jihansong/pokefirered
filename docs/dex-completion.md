# 도감 완성 계획: 전국도감 1~386번 입수 경로

Thunder Yellow(leafgreen 빌드)에서 전국도감 386종을 모두 게임 안에서 얻을 수 있게 만든 작업의 계획과 결과 기록이다.

## 현황 (작업 전)

- 입수 가능 192종, 불가 194종. 기준은 한 세이브에서 교환 없이 얻을 수 있는지다(야생·선물·교환 NPC·진화·교배 포함).
- 계산 방법: 야생 테이블(leafgreen판만, 알터링 동굴 2~9번 세트 제외), 스크립트의 `givemon`·`setwildbattle`·`giveegg`·`seteventmon`, 게임 내 교환, 숨겨진 동굴·필드 현상·벌레잡기 대회·배회 전설을 입수처로 보고, 혼자서 가능한 진화(레벨·돌·친밀도)와 교배로 넓혔다.
- 입수 불가였던 이유:
  - **버전·지역 한정 일반 포켓몬**: 옐로에 없는 1세대(아보, 식스테일, 또가스, 에레브), 파이어레드 전용 세비 제도 출현(우파, 니로우, 침바루, 딜리버드, 무장조), 미스터리 선물 전용 알터링 동굴 세트(메리프, 피콘, 델빌, 깜지곰, 에이팜, 단단지, 노라키, 루브도), 3세대 대부분.
  - **통신교환 진화**: 후딘, 괴력몬, 딱구리, 팬텀, 왕구리, 야도킹, 강철톤, 핫삼, 킹드라, 폴리곤2, 헌테일, 분홍장이.
  - **특수 진화**: 에브이·블래키(FR/LG에 시계가 없음), 밀로틱(FR/LG에서 아름다움을 올릴 수 없음).
  - **전설·환상**: 배회 3마리 중 세이브마다 1마리만 나옴(앤테이·스이쿤 불가), 티켓을 주지 않는 개정판 0(루기아·칠색조·데오키시스), 원래 배포 전용(세레비·지라치), 레지 3마리.
  - **스타터**: 성도·호연 스타터 6계열.

## 방침

1. 전설·환상은 야생 테이블에 넣지 않고 전용 장소의 1회성 이벤트로 둔다.
2. 칸토의 옐로식 테이블은 유지한다. 새 종은 **같은 테이블 안에 이미 중복된 칸**(대부분 4%·1% 칸)만 바꿔 넣으므로 옐로에 있던 종은 모두 그대로 나온다. 세비 제도와 불씨산은 원래 리프그린 테이블이라 기존 종을 남기는 선에서 자유롭게 바꿨다.
3. 스타터는 야생에 넣지 않고 NPC가 준다.
4. 세이브 구조(SaveBlock)는 바꾸지 않는다. 새 기록은 기존에 비어 있던 플래그·변수만 쓴다.
