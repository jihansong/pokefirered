# v0.11.0 대사 초안 — Petalburg 구역 (Z3 2차)

`docs/v0.11.0-plan.md` 8장·12.1의 기획 몫 중 **Petalburg 구역**이다(Littleroot 구역 `docs/v0.11.0-dialogue-littleroot.md`와 같은 방식). 게임 파일은 고치지 않았다. 코드 블록을 `tools/hoenn_import/patches/<Map>.text.inc`에 옮기면 된다.

- 범위: Petalburg City, 체육관, 민가 2, 마트, 포켓몬센터 1·2층, WALLY의 집, 104번 도로, BRINEY 씨 오두막, 꽃집(Pretty Petal), Petalburg Woods — **12맵**. 102번 도로는 E5 두 줄만 더한다.
- 기준: `textaudit.py --map …`(12맵): 사용 중 101개, 전부 원문, 무해 5(이름판 3·방향 표지판 2) → **다시 쓸 것 96개**.
- 이벤트: E4 NORMAN(로비), E5 WALLY 포획 시범, E6 숲(아쿠아단·로켓단 더블·나무지기), E9 BRINEY 배, E11 물짱이, E12 선물(기적의씨·기술머신09·잠깨비열매·하양허브·매일 열매·슈퍼볼), E13 소문.
- 구역 밖: Wanda 대사 1 갱신 + 2 새로(Z2), BRINEY 배 복귀 2(Z1), 소문 4(카이나), Mauville·Lilycove 센터의 스크립트 없는 NPC 2.
- 폭 검사: `tools/qa/textwidth.py` **208px 초과 0**, `{STR_VAR_n}` 수동 확인 0. 가장 긴 줄 203px.
- 빈 약속: `PROMISE` 정규식 + 계획 8.2 보강어가 걸리는 말은 실제로 주는 대사(꽃집 소녀 H2)뿐이다. 주는 NPC는 모두 "받은 뒤"·"가방 가득" 대사가 있다.
- 표기: Littleroot 문서와 같다(대문자 고유명사, “ ”, `…`, 영국식 철자).
