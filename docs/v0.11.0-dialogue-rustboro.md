# v0.11.0 대사 초안 — Rustboro 구역 (Z3 3차, 마지막)

`docs/v0.11.0-plan.md` 8장·9장·12.1의 기획 몫 중 **Rustboro 구역**이다(Littleroot·Petalburg 문서와 같은 방식). 게임 파일은 고치지 않았다. 코드 블록을 `tools/hoenn_import/patches/<Map>.text.inc`에 옮기면 된다(블록 하나에 여러 맵이 있으면 라벨 앞머리의 맵 이름대로 나눈다).

- 범위: Rustboro City와 건물 19맵(체육관·스쿨·데봉 1~3층·커터의 집·민가 3·아파트1 1·2층·아파트2 1~3층·마트·포켓몬센터 1·2층), 115·116번 도로, 116번 도로 굴착꾼 쉼터, Rusturf Tunnel, 105번 도로 — **23맵**.
- 기준: `textaudit.py --map …`(23맵): 사용 중 181개, 전부 원문, 무해 10(이름판·방향 표지판 6, 울음 4) → **다시 쓸 것 171개**. 빠진 라벨 0(초안 라벨 목록과 textaudit 원문 목록을 대조함).
- 이벤트: E7 ROXANNE(STONE 배지·기술머신39·피카츄 분기), E8 데봉 소포(Rustboro → 116번 도로 → 터널 → Z1 STERN → 데봉 3층), E10 터널 개통·WANDA, E12 선물·교환(빈 약속 2건 처리), E13 소문 22~25, 9장 경계 안내판 3 + Z1·Z2 갱신.
- 폭 검사: `tools/qa/textwidth.py` **208px 초과 0**, `{STR_VAR_n}` 수동 확인 0. 가장 긴 줄 207px.
- 빈 약속: 정규식에 걸리는 말은 실제로 주는 대사 둘뿐(`StoneThanks` "Take this" → 학습장치, `RoxanneBadge` "received" → 배지). 주는 NPC는 모두 "준 뒤"·"가방 가득" 대사가 있다.
