# 로이·로사 v9 — 네이티브 명암 정리 시안

v8의 게임용 64×64 자산에서 **머리카락 17픽셀, 장갑 경계 9픽셀**을 정리했다. 크기·비율·투명 외곽·15색 팔레트는 그대로다. 새 고해상도 원화를 만들거나 이미지를 재생성한 작업이 아니다.

- 로이: 머리카락에 섞인 회색/파랑을 기존 보라색으로 바꾸고, 떨어져 있던 오른쪽 하이라이트와 그림자를 작은 색 덩어리로 정리했다.
- 로사: 머리의 회색 픽셀과 밝은 머리 부분에 고립된 짙은 점을 정리했다.
- 장갑: 로이 오른손의 엄지/손가락 아래쪽, 로사의 구부린 장갑 아래 경계에 기존 그림자 색을 연결했다.
- 눈: v8의 흰자·홍채 배치를 유지했다. 더 바꾸는 것이 좋아진다는 근거가 없어 해당 영역 수정은 0이며 별도 확대 비교를 제공한다.

## 바로 검토할 파일

- `comparison-v8-v9-original-1x-8x.png`: v8, v9, 원작 엘리트 커플을 동일한 1배·최근접 8배로 대조.
- `pixel-diff-v8-v9.png`, `changed-pixels-mask.png`: 실제 변경 26곳의 위치.
- `eye-comparison-v8-v9.png`: 눈 주변의 확대 비교. 눈 픽셀은 변경하지 않았다.
- `jessie-james-v9-64.png`, `jessie-james-v9-8x.png`: 투명 PNG와 확대 검토본.
- `jessie-james-v9.4bpp`: 2,048바이트 게임용 타일 데이터.
- `jessie-james-v9.gbapal` / `.pal`: v8과 동일한 팔레트.
- `changes.json`: 수정 좌표·이전/이후 색 인덱스·각 수정의 목적.
- `validation.json`: 전체 디코드 및 보존 검사.

## 검증과 판단

4bpp를 독립적으로 디코딩한 **4,096픽셀 전부 PNG와 일치**한다. 팔레트 바이트 동일, 투명 실루엣 변경 0, v8 원본 파일 12개 해시 보존, 64×64 및 불투명 15색 유지에 통과했다. 승인된 v4 전신 비율을 다시 조정하지 않았다.

1배·8배와 원작 대조에서 머리카락의 회색 잡색과 불연속 명암이 줄고 장갑 아래 경계가 조금 더 이어지는 것을 확인했다. 변화는 작은 네이티브 정리이며, 전신을 다시 그리거나 원작과 같은 완성도로 판정한 결과가 아니다. 표정과 손의 해부학적 세부 묘사는 기존 승인 원화와 작은 캔버스의 한계가 남는다.

이번 버전은 명시적으로 선택한 좌표의 로컬 4bpp 데이터를 편집하고 PNG를 내보낸 것이다. 이미지 모델·다른 생성 서비스·Piskel UI를 사용했다고 주장하지 않는다. 검증 스크립트는 자산을 읽어 비교 이미지를 만들며 캐릭터 원본을 바꾸지 않는다. 원본, Codespaces, ROM, 사용자 세이브는 수정하지 않았다.
