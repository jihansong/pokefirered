# 이벤트 로드맵 (Thunder Yellow)

앞으로 추가를 검토할 이벤트 후보 목록이다. 아직 구현하지 않았으며, 이 문서는 코드를 바꾸지 않는다.

- **1부**: 하트골드·소울실버(HGSS)와 블랙·화이트(BW, BW2 포함) 이벤트 중에서 1~3세대 포켓몬만으로 재현할 수 있는 것.
- **2부**: 포켓몬 도시전설·우라와자(裏技) 소문을 실제 이벤트로 만든 것.

위치는 이 저장소(FR/LG 기반)의 칸토·세비 제도 맵 이름을 기준으로 적었다.

## 공통 전제

- **시계 없음**: FR/LG에는 실시간 시계(RTC)가 없다(`src/field_tasks.c`에서 RS의 RTC 기능이 제거됨). 원작에서 요일·시간대에 따라 열리는 이벤트는 걸음 수 카운터, 전당등록 횟수, 게임 내 가상 요일 변수 같은 대체 조건을 쓴다.
- **이미 구현된 것**: "트럭 밑의 뮤"는 이미 구현되어 있어 후보에서 뺐다.
- **난이도 기준**
  - **하**: 스크립트·텍스트, 기존 맵에 오브젝트 추가 정도.
  - **중**: 새 스페셜(C 코드)이나 새 그래픽, 작은 새 맵이 필요.
  - **상**: 새 시스템, 여러 맵에 걸친 연출, 전투·필드 엔진 수정이 필요.
- **새 리소스**: 플래그·변수는 대부분 필요하므로 표에는 따로 적지 않았다. 그래픽·맵·음악·C 코드처럼 규모가 있는 것만 적었다.
