# v0.6.0 구현 계획 — "최강을 향한 길"

v0.5.0(로켓단의 여정) 다음 버전. 전당등록 이후 할 거리를 채우는 **강자·포스트게임 편**으로, `docs/events-roadmap-2.md`에 남아 있던 후보 중 서로 이어지는 넷(3·10·14·15번)과 알려진 작은 문제들을 묶었다. 이 문서는 계획만 담으며, 승인 전에는 코드를 바꾸지 않는다.

## 브랜치와 공통 규칙

- 브랜치 `road-to-the-top`(master = v0.5.0에서 분기). 항목마다 빌드 → 에뮬레이터 캡처 → 세이브 비교 → 커밋. push·머지·태그·패치·릴리스는 캡처 확인 뒤 요청이 있을 때만.
- 세이브 구조는 바꾸지 않는다. 새 플래그·변수는 빈 번호만 쓴다(현재 빈 플래그 531개, 빈 변수 `VAR_0x40xx` 56개).
- 세이브 검사: `saves/v0.1.0.sav`·`v0.2.1.sav`·`pokemonthyl_v3.gba.sav`를 기존 기준 ROM과 비교(`savetest_all.sh`). v0.5.0 릴리스 ROM(`~/qa-base-v0.5.0`)을 기준으로 하는 네 번째 검사를 추가한다.
- 새 맵은 맵 그룹 끝에, 새 레이아웃은 `layouts.json` 끝에 붙인다(기존 맵·레이아웃 번호가 밀리지 않게).
- 트레이너: 칸토 번호는 753~767의 15칸만 남았다. 그보다 많이 필요하면 호연 트레이너 뒤에 붙이고, 승리 기록은 `SaveBlock2.hoennTrainerFlags`(1024비트 중 호연이 약 520 사용)의 남은 칸을 쓴다. 호연 임포트 스크립트를 다시 돌려도 지워지지 않도록 별도 파일로 둔다.
- 새 이벤트마다 게임 안 힌트 NPC(소문 수집가 등)를 둔다. 새 그림은 FRLG 화풍으로, 가능하면 기존 그림을 다시 칠해서 만든다.
- 끝나면 `docs/events-roadmap-2.md` 구현 기록과 공략집 새 장·이벤트 색인을 갱신한다.

## 1. 상록숲의 옛 트레이너 (로드맵 2 · 3번) — 작음

- **조건**: 회색배지 이후, **밤**(20~3시)에 상록숲 안쪽 공터.
- **내용**: 옛날 복장의 트레이너가 "요즘 기술은 모르겠군"이라며 1세대 종·1세대 기술만 쓰는 파티(도구 없음, 배지 수에 따라 3단계 레벨)로 대결한다. 이기면 1세대에 있던 기술머신 중 하나를 주고 그날 밤에는 사라진다. 다음 날 밤 다시 나타난다(날짜는 시간대 시스템의 날 수, 변수 1개).
- **그래픽**: 벌레잡이 소년·등산가 NPC를 바랜 색으로 다시 칠함.
- **힌트**: 무지개시티 소문 수집가, 상록숲 입구 NPC.

## 2. N 오마주 — 포켓몬의 목소리를 듣는 청년 (10번)

- **본편 3회**: ① 회색시티 박물관 앞(회색배지 직후) ② 포켓몬타워 7F(후지 노인 구출 직후) ③ 실프주식회사 11F(비주기 격퇴 직후). 매번 짧은 대화와 1회 대결. 파티는 점점 강해진다.
- **피카츄와 연결**: "이 아이의 목소리가 들린다"며 오 박사의 피카츄 친밀도(기분)에 따라 대사가 세 갈래로 달라진다. 피카츄가 파티에 없으면 그 사실을 말한다.
- **포스트게임**: 6의섬 물의 샛길 끝에 새 맵 "은빛 오두막"(작은 실내 1개, 기존 집 타일 재사용). 전당등록 뒤 방문하면 최종전을 치르고, 이기면 청년이 떠나며 편지(중요한 물건, 빈 아이템 번호)를 남긴다.
- **파티**: 1~3세대만. 버려진 포켓몬·친구가 된 포켓몬이라는 설정에 맞춘 구성(예: 조로아크 대신 메타몽·킬리아 같은 변신·교감 계열). 최종전에는 전설 1마리를 넣는다(후보는 아래 "결정" 3번).
- **그래픽**: 청년 필드 그림과 전투 그림은 기존 인물(쿨트레이너 남 등)의 머리·옷 색을 바꿔 만든다. 이름은 아래 "결정" 참고.

## 3. 은빛산 — 정상의 최강 트레이너 (15번)

- **조건**: 전당등록 후, 칸토 도감 150종 완성 **또는** 4번 토너먼트 우승.
- **입구**: 7의섬 세바트 협곡 끝에서 새 던전으로 연결. 새 맵 4개(산기슭 동굴 2층 + 눈 덮인 산길 + 정상). 동굴은 기존 동굴 타일셋, 산길·정상은 4의섬 얼음 동굴·세비 협곡 타일을 섞어 쓴다. 산길에는 눈 날씨(FRLG에 남아 있는 `WEATHER_SNOW`가 제대로 도는지 먼저 확인, 안 되면 안개로 대체).
- **야생**: 레벨 60~70대. 도감 서식지 작업(`docs/dex-habitat.md`)과 겹치지 않게 하고, 새 서식지가 생기는 종은 도감 분포에 자동 반영된다(HGSS 은빛산 참고: 포푸니·마기라스 계열·꾸꾸리 계열 등).
- **정상**: 대사 없이 "…"만 남기는 최강 트레이너와 대결. HGSS 레드 파티를 따라 피카츄 88, 에브이 84, 잠만보 82, 이상해꽃·리자몽·거북왕 84(1~3세대라 그대로 가능). 이기면 조용히 사라지고, 정상에 기념 오브젝트가 남는다. 재대결은 하루 1회.
- **그래픽**: 최강 트레이너는 FRLG 남자 주인공 그림을 모자·옷 색만 바꿔 쓴다(플레이어가 남자여도 구분되게).

## 4. 세계관 통합 챔피언 토너먼트 (14번)

- **조건**: 전당등록 후, 세비 제도 이야기(루비·사파이어 회수) 완료.
- **장소**: 석영고원 포켓몬센터 1층에 접수원을 두고 새 맵 "토너먼트 홀"(로비 1 + 경기장 1)로 연결. 경기장은 쓰이지 않던 트레이너 타워 레이아웃을 재사용한다.
- **방식**: 8명 토너먼트, 3연승하면 우승. 경기 사이에만 회복. 참가자는 관장 8명·사천왕 4명·라이벌·오박사·N·로사&로이(더블배틀 1경기) 중에서 7명을 무작위로 뽑는다. 파티는 Lv65~75의 토너먼트 전용 파티(16개 안팎, 호연 트레이너 뒤에 추가).
- **대진표**: 경기마다 텍스트 창으로 대진과 결과를 보여 주는 간단한 방식(추천). 그래픽 대진표 화면은 선택(아래 결정).
- **보상**: 첫 우승 시 트로피(주인공 방 장식)와 이상한사탕·강한 도구 묶음. 이후 우승마다 작은 보상. 요일 개최는 두지 않는다(언제든 도전).

## 진행 상황 (2026-09-22)

1·2·3·4는 구현·에뮬레이터 확인·커밋 완료(`road-to-the-top`), 기록은 `docs/events-roadmap-2.md` 구현 기록 7~10번. 5-1(공항 벽 마트 문구)·5-3(호연 지도 해안선)도 완료. 5-2(공중날기 피카츄 풍선)는 그림 작업이라 별도 작업자에게 맡겨 진행 중. 캡처 묶음: `docs/screenshots/v0.6.0_items.png`.

에뮬레이터로 확인한 범위: 1번은 등장·대사·2단계 대결·기술머신 지급·퇴장까지 전부. 2번은 회색시티(전부)·실프(등장과 대사)·포켓몬타워(등장)·오두막 최종전(전투·퇴장·편지)까지. 3번은 입구·눈보라 차단과 되돌리기·얼음 타일셋·정상 대결·퇴장까지. 4번은 접수원·홀 입장·추첨·대진 안내·실제 대결(사천왕 독수)·트로피 표시까지. 4번의 3연승 뒤 시상 대사만 테스트 파티가 Lv70대를 못 이겨 확인하지 못했다(스크립트 8줄, 트로피·플래그 경로는 확인함).

## 순서

1(옛 트레이너, 작아서 먼저) → 2(N 본편 3회 + 오두막) → 3(은빛산) → 4(토너먼트: N·오박사 파티가 먼저 있어야 함) → 5 → 힌트·문서·공략집 새 장 → 캡처 확인 → v0.6.0.
