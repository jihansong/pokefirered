# 정면 전투 자세 타이틀 PNG 시안

사용자가 제공한 `15-ready-crouch.png`의 정면 자세를 Adobe로 배경 분리·벡터화한 뒤, SVG 원본의 눈꺼풀·눈빛·입선을 편집했습니다. 잘린 꼬리 끝을 이어 그리고 꼬리 레이어를 작게 배치하여 전신이 타이틀에 들어가도록 했습니다. **참고 이미지에서 파생한 편집 시안이며, 새로 생성한 독창적인 포즈 원화는 아닙니다.**

- `title-front-candidate-240x160.png`: 실제 GBA 화면 크기 정지 시안
- `title-front-candidate-4x.png`: 픽셀을 그대로 4배 확대한 검토본
- `front-mono-fitted.svg` / `.png`: 선택한 86×90 피카츄 셀
- `comparison-4x.png`: 기존 v3와 정면 시안 비교
- `source-cutout.png`, `source-editable.svg`: Adobe가 반환한 원본 편집 재료, 보존
- `native-edit.json`, `validation.json`, `provenance.json`: 편집·색상·배치·출처 기록

눈과 얼굴이 작은 아래 방향 시안보다 잘 보이도록 정면을 사용했습니다. 몸통과 얼굴 비율은 제공된 그림을 유지했고, 팔을 길게 늘리지 않았습니다. 꼬리만 60% 크기로 뒤쪽에 배치하고 뿌리를 연결했습니다. 볼을 포함한 모든 색은 노랑·금색·갈색 계열로 정리했습니다.

로고·TM·THUNDER YELLOW VERSION·PRESS START·GAME FREAK 글자는 원본 좌표와 화소를 유지했습니다. 3,079개의 캐릭터 불투명 화소가 모두 표시되며 문구 겹침이나 잘림은 없습니다. 캐릭터는 투명색 외 15색이고 RGB555 채널값을 사용합니다. 배경 번개 띠는 기존 타이틀의 조각을 반복 배치한 정지 구도입니다.

이 시안은 PNG 검토 단계입니다. GIF 제작·음악 동기화·ROM 반영·하드웨어 팔레트/VRAM 검증을 완료했다는 뜻이 아니며, 사용자 승인도 아직 없습니다. 원본 그림과 기존 v3는 변경하지 않았습니다.
